# Agriculture Marketplace

A professional, production-ready Flask marketplace for farmers and buyers.

## Features
- Farmer, buyer, and admin roles
- Marketplace with search and filtering
- Product detail pages and reviews
- Shopping cart and checkout simulation
- Responsive landing page and dashboards

## Setup
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

## Default Accounts
- Admin: admin@example.com / admin123
- Farmer: farmer@example.com / farmer123
- Buyer: buyer@example.com / buyer123

## Structure
- app.py: main Flask application
- templates/: HTML templates
- static/: CSS, JS, images, uploads
